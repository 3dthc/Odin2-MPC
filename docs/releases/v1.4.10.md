# Odin 2 v1.4.10

## What's new
- **Instruments browser card:** Odin 2 now shows as its own card in Sounds > INSTRUMENTS. Tapping it opens the plugin's preset list (after the restart the installer does).
- **USER bank:** load your own `.odin` patches. Copy them into the `User Presets` folder inside the plugin's folder on the MPC (`Documents/Odin2 MPC/User Presets` on a computer) and reopen Odin 2: they appear as the USER bank on BROWSE, the top bar and MPC's PRESET menu (up to 30). A project saved on a user patch keeps the whole sound, even if the file is later changed or removed. ([#3](https://github.com/3dthc/Odin2-MPC/issues/3))
- **Presets on the Instruments card:** tapping the Odin 2 card in Sounds > INSTRUMENTS now lists all 261 factory presets; pick one to load Odin 2 with that sound.
