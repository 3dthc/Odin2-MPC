## Fixes

- **Lower CPU on Gen2 MPCs (MPC Live 3 and other 64-bit models).** The Gen2 build didn't switch on the processor's
  fast handling of tiny numbers while Odin renders, so filter and effect tails fading towards silence ran much slower
  than they should: in measurements a released chord's tail cost about 5 times as much on average (up to 28 times),
  and held notes about 8 % more. This was the high CPU reported in issue #1.
- **Loads on Gen1 MPCs running MPC OS 2.x.** On an MPC Live with MPC OS 2.15.1, versions 1.4.4 to 1.4.7 failed to load
  with `version 'GLIBCXX_3.4.29' not found`: the armv7 build needed a newer C++ runtime than MPC OS 2.x has. The armv7
  build is now compiled against the older runtime (GLIBCXX 3.4.28 at most) and still loads on MPC OS 3.x (issue #2).

No other changes since 1.4.7.
