# Odin 2 v1.4.9

## What's new
- **MPC OS 3.10.1:** the plugin folder carries a `plugin.json`, so it can be copied straight into `VST2 Plugins`, and an Akai SDK-format zip (`-mpc-sdk.zip`, one folder for every MPC) comes with the release.
- **Desktop VST3 for MPC Desktop and DAWs:** `Odin-2-1.4.9-macos-vst3.zip` (one file for Apple Silicon and Intel Macs, with the same touchscreen skin in the plugin window) and `Odin-2-1.4.9-windows-vst3.zip` (64-bit, with the same skin in the plugin window).
- **Device projects open on the computer:** the VST3 has the VST2's official replacement ID, so a project saved on the MPC with this plugin loads it in MPC Desktop (controller mode) instead of showing a missing plugin, with the same sound and settings. A project saved on the desktop opens on the MPC the same way.
- **Window size on the desktop:** right-click the plugin window (Control-click on a Mac) and pick 50% to 125%. It opens at 75% and remembers your choice for all of these plugins.

## Fixed
- Desktop: the bank and patch arrows work again (a quick click was lost before).
- Windows: MPC 3 now loads the plugin (before, it was listed but couldn't be added: a Windows-only interface ID layout bug). It's a single `.vst3` file with its skin and sounds inside (unpacked once on first load), the format MPC 3 scans; no extra folders.
- Desktop parameter list: in MPC 3 (controller mode, the MPC's screen) and in DAWs the plugin now lists only its sound controls, the knobs, switches and Q-Link controls, instead of every internal value (themes, browser, screen text). Picking a preset no longer marks it as edited (no "*").
- Mac: macOS no longer blocks the plugin as "can't be verified" when installed with the one-line Terminal command in the zip's README.txt (it also unblocks copies you already installed).
